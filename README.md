# IoT-Based Smart Plug Energy Meter

An ESP32-based smart plug designed to monitor voltage, current, power, and energy consumption in real time.

## Features

- Real-time voltage monitoring
- Current measurement
- Power consumption monitoring
- Energy consumption tracking
- LCD display
- Automatic load control using relay
- ESP32-based IoT system

## Hardware

- ESP32
- ACS712 Current Sensor
- ZMPT101B Voltage Sensor
- 16x2 I2C LCD
- Relay Module
- AC Load

## Software

- Arduino IDE
- Embedded C/C++
- ESP32
- LiquidCrystal_I2C

## Applications

- Home energy monitoring
- Appliance-level energy monitoring
- Energy-saving systems
- Smart home applications
